# KORBAN Consulting Web

A multi-page web implementation for **KORBAN Consulting**, supporting Korea–Bangladesh business and operational information.

## Project context

KORBAN works across consulting, overseas business support, logistics, travel/business-trip support, and partner coordination.

This repository contains a static web implementation used to organize and present that service information online.

## Pages / areas represented

- Company introduction
- Client information
- Company setup / business support
- Accounting-related information
- Labor-related information
- Partner information

## What this project demonstrates

- Translating real business operations into web information architecture
- Building and maintaining multi-page business content
- Working with large existing HTML/CSS assets
- Connecting technical implementation with actual consulting/operations needs

## My role

I worked across both **digital implementation** and the underlying business operations, which helped me design pages around real customer and internal workflow needs rather than only visual requirements.
